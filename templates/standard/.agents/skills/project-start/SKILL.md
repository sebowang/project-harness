# Project Start

## Steps

1. Read the applicable `AGENTS.md` instruction chain.
2. Read `docs/project-map.md` and `docs/verification.md`.
3. Read task-relevant PRD, accepted ADR, reference and module README files.
4. Inspect `git status --short` and preserve existing work.
5. Summarize the goal, verified architecture facts, affected areas, validation path, risks and open questions.

Do not edit code during context recovery. If documents conflict with current code, report the conflict before choosing a direction.
