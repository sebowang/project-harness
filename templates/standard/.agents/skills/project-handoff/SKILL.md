# Project Handoff

Create or update a single task-specific handoff file only when work must continue in another session or with another engineer.

Include:

- goal and acceptance criteria
- completed work and changed files
- actual validation commands and results
- unresolved issues and risks
- next three concrete steps
- exact resume point

Do not create parallel session-state, progress-map and command-history files. Remove or archive the handoff when the task is complete according to the repository's normal documentation policy.
