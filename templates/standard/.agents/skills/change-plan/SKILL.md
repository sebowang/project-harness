# Change Plan

## Steps

1. Restate the observable outcome and acceptance criteria.
2. Inspect relevant source, callers, tests and documents.
3. Separate verified facts, assumptions and unresolved choices.
4. Define scope, non-scope and the smallest effective change.
5. Identify files likely to change and compatibility risks.
6. Select build, test, Harness and manual verification evidence.

Do not create speculative abstractions or unrelated cleanup work. If uncertainty would materially change the implementation, pause and request a decision.
