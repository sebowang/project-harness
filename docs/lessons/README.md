# Lessons Learned

本目录记录会影响后续工作的长期经验：用户纠正、重复失败的根因、操作陷阱和经过验证的实践。

它不是 PRD、Decision Record、源码事实库或临时日志。内容分类不清时，优先使用 `docs/workflows/knowledge-capture.md` 的路由规则。

建议每条经验使用一个文件，文件名采用 `short-title.md`，正文包含：

```markdown
# 经验标题

## 状态
Observed | Accepted | Retired

## 场景与症状

## 经验

## 后续动作

## 证据

## 适用范围

## 关联文档
```

如果经验已经升级为强制规则、产品要求、长期决策或当前事实，应在关联文档中维护主内容；本目录只保留经验的来由和适用边界，避免重复维护。
